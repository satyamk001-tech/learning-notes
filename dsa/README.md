## 🎯 Classification by Algorithmic Paradigm

- **Linear Data Structures:** Arrays, Strings, Singly Linked Lists, ArrayLists.
- **Divide and Conquer:** Merge Sort, Quick Sort, Optimized Fast Power ($x^n$).
- **Two Pointers Technique:** Trapping Rain Water, 3Sum, Container With Most Water, Palindrome Check.
- **Greedy Algorithms:** Stock Buy & Sell, Activity Selection principles.
- **Exhaustive Search & Pruning:** Backtracking (N-Queens, Sudoku, Subsets, Permutations).
- **Bitwise Arithmetic:** Fast parity checking, single number detection, power of two, fast exponentiation.
- **Graph Foundations:** Representations (Adjacency Matrix vs List), Topological ordering.

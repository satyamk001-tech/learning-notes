# Java Collections Framework (ArrayList)

Linear dynamic list operations and standard collection utilities:
- `arraylist.java`: Dynamic array instantiation, growth factor, CRUD operations.
- `arraylistsize.java`: Iteration and size retrieval.
- `arraylistmax.java`: Linear scan to find the maximum element.
- `arraylistswap.java`: Index-based element swapping.
- `arraylistsort.java`: Ascending and descending sort via `Collections.sort`.
- `arraylistmultidimen.java`: 2D multi-dimensional dynamic ArrayLists.

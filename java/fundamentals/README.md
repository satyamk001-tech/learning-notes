# Java Fundamentals

Core building blocks of Java programming:
- **[basics/](basics/):** Hello World, variables, datatypes, scanner, arithmetic operations.
- **[conditionals/](conditionals/):** If-else, switch-case, ternary operators, calculators.
- **[loops/](loops/):** While, for, do-while loops, number reversal, range iteration.
- **[patterns/](patterns/):** 15 pattern printing programs for nested loop logic.
- **[functions-methods/](functions-methods/):** Call by value, primes, binomial coefficients, base conversions.

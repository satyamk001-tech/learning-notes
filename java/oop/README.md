# Object-Oriented Programming (OOP) in Java

Implementations covering object-oriented paradigms:
- `OOPS.java`: Class and object creation, access modifiers, getters/setters.
- `OOPSconstructor.java`: Constructor basics and initialization.
- `OOPStypesofcons.java`: Non-parameterized vs parameterized constructors.
- `OOPScopycons.java`: Copy constructors, shallow vs deep copying.
- `OOPSabstract.java`: Abstract classes, abstract methods, interface realization.
- `overloadingdatatypes.java`: Compile-time polymorphism via method overloading.
- `questionstatic.java`: Static variables, methods, and shared memory allocation.
- `zoo.java`: Class relationships and object modeling.

# Java DSA Learning Roadmap (5-Month Milestone)

## 📅 Timeline: Months 1 to 5 (Completed)

### Month 1: Java Fundamentals & Flow of Control
- [x] Java environment setup, JDK compilation, JVM architecture.
- [x] Primitive datatypes, type conversion and casting rules.
- [x] Operators: Arithmetic, Relational, Logical, Assignment.
- [x] Control Flow: `if-else`, ternary, `switch-case` statements.
- [x] Loops: `for`, `while`, `do-while` loops, break and continue.
- [x] 15 Nested loop pattern printing problems.

### Month 2: Functions, OOP & Number Theory
- [x] Methods, call-by-value semantics, method overloading.
- [x] Number systems: Binary $\leftrightarrow$ Decimal conversions.
- [x] Prime number checking and range sieving.
- [x] Object-Oriented Programming (OOP):
  - [x] Classes, Objects, `this` reference.
  - [x] Constructors (Default, Parameterized, Copy).
  - [x] Shallow vs Deep Copying.
  - [x] Abstraction and Interfaces.
  - [x] Static keyword and memory placement.

### Month 3: Arrays, 2D Matrices & Collections Framework
- [x] Array creation, updates, and linear scan.
- [x] Two-pointer array reversal and pair generation.
- [x] Subarray algorithms:
  - [x] Brute force $\mathcal{O}(N^3)$
  - [x] Prefix sum optimization $\mathcal{O}(N^2)$
  - [x] Kadane's Algorithm $\mathcal{O}(N)$
- [x] Classical Array Problems:
  - [x] Trapping Rain Water $\mathcal{O}(N)$
  - [x] Best Time to Buy and Sell Stock $\mathcal{O}(N)$
  - [x] 3Sum and Container With Most Water
- [x] 2D Matrices:
  - [x] Spiral Matrix Traversal
  - [x] Diagonal Summation $\mathcal{O}(N)$
  - [x] Staircase Search in 2D Sorted Matrix $\mathcal{O}(N+M)$
- [x] Java Collections Framework:
  - [x] Dynamic `ArrayList` operations, growth factor, 2D ArrayLists.

### Month 4: Strings, Bit Manipulation & Sorting Algorithms
- [x] String immutability, String Constant Pool, `StringBuilder`.
- [x] Palindromes, anagrams, string compression.
- [x] Bit Manipulation:
  - [x] Bitwise operators (`&`, `|`, `^`, `~`, `<<`, `>>`).
  - [x] Get, Set, Clear, Update $i$-th bit.
  - [x] Clear last $i$ bits and bit range.
  - [x] Power of 2 test (`n & (n - 1) == 0`).
  - [x] Fast exponentiation in $\mathcal{O}(\log N)$.
- [x] Sorting Algorithms:
  - [x] Bubble Sort (Standard & Optimized $\mathcal{O}(N)$).
  - [x] Selection Sort.
  - [x] Insertion Sort.
  - [x] Counting Sort $\mathcal{O}(N+K)$.
  - [x] Inbuilt sorting (`Arrays.sort`).

### Month 5: Divide & Conquer, Recursion, Backtracking & Core Graphs
- [x] Advanced Sorting:
  - [x] Merge Sort (Divide & Conquer $\mathcal{O}(N \log N)$).
  - [x] Quick Sort (Lomuto Partitioning).
- [x] Recursion deep dive:
  - [x] Call stack analysis, recursion tree.
  - [x] Optimized fast power ($x^n$ in $\mathcal{O}(\log N)$).
  - [x] Tiling Problem ($2 	imes N$).
  - [x] Remove duplicate characters in strings.
  - [x] Friends Pairing Problem.
  - [x] Binary strings without consecutive 1s.
- [x] Backtracking:
  - [x] Subsets / Power set ($2^N$).
  - [x] Permutations ($N!$).
  - [x] $N$-Queens Problem ($N 	imes N$).
  - [x] Grid Unique Paths.
  - [x] $9 	imes 9$ Sudoku Solver.
- [x] Linked Lists:
  - [x] Singly Linked List Node, head/tail pointers, linking, iterative traversal.
- [x] Graphs:
  - [x] Adjacency Matrix and Adjacency List representations.
  - [x] Topological order matrix foundation.

# Homework, Assignments & Practice Sets

This directory preserves curated practice problem sets, university course assignments, and daily coding challenge exercises.

---

## 📂 Subdirectories

- **[assignments/](assignments/):** Course assignments exploring Java variable declaration, type promotion, input averages, and variable scoping rules (`aone.java` to `afive.java`).
- **[daily-questions/](daily-questions/):** Daily problem sets focusing on conditionals, fever check, switch-case week navigation, leap years, and loop variable increments (`qone.java` to `qfive.java`).
- **[practice-basics/](practice-basics/):** Fundamental algorithmic exercises:
  - `addone.java`: Array digit increment.
  - `comparearray.java`: Array comparison.
  - `numberswap.java`: Variable swapping without third variable.
  - `pali.java`: Number palindrome validation.
  - `searchseven.java`: Counting specific numbers in 2D grids.
  - `sumofsecondarray.java`: Row sum in 2D matrices.
  - `transposeofmatrix.java`: Matrix transposing.
  - `uppertolower.java`: Bitwise casing.
  - `avera.java` & `eve.java`: Accumulator patterns.
- **[recursion-practice/](recursion-practice/):**
  - `recruques1.java`: Finding all occurrence indices of an element in an array recursively.
  - `recurques2.java`: Number-to-English-words recursive translation practice stub.

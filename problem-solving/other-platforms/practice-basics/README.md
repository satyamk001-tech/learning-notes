# Practice Algorithms & Utilities

General practice exercises in arrays, matrices, and number manipulation:
- `addone.java`: Array digit increment.
- `comparearray.java`: Comparing two arrays for element equivalence.
- `numberswap.java`: Swapping two numbers without a temporary variable.
- `pali.java`: Number palindrome check using digit reversal.
- `searchseven.java`: Counting occurrences of target key in a 2D matrix.
- `sumofsecondarray.java`: Summing elements of the second row in a 2D matrix.
- `transposeofmatrix.java`: Matrix transposing ($M \times N \to N \times M$).
- `uppertolower.java`: Bitwise character conversion.
- `avera.java` & `eve.java`: Accumulator algorithms.
- `Solution.java`: General practice problem solver template.

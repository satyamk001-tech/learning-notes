# LeetCode 867: Transpose Matrix

- **Platform:** LeetCode
- **Problem Number:** 867
- **Difficulty:** Easy
- **Core Pattern:** Matrix / 2D Array

---

## 📖 Problem Description
Given a 2D integer array `matrix`, return the transpose of `matrix`.

---

## 💡 Algorithmic Intuition & Approach
Create a new matrix of dimensions `cols x rows`. Copy elements such that `transposed[j][i] = matrix[i][j]`.

---

## ⚡ Complexity Analysis
- **Time Complexity:** $O(M * N)$
- **Space Complexity:** $O(M * N) for transposed matrix$

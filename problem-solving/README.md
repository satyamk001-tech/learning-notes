# Problem Solving & Competitive Programming

This directory organizes solutions to coding challenges across multiple competitive programming and interview preparation platforms.

---

## 🗂️ Platform Index

- **[LeetCode (27 Problems)](leetcode/):** Solutions organized by problem number, including problem descriptions, approaches, complexity analysis, and verified Java code.
- **[Codeforces (5 Problems)](codeforces/):** Timed contest solutions with custom I/O and greedy / number-theoretic algorithms.
- **[Other Platforms & Practice](other-platforms/):**
  - **[Assignments](other-platforms/assignments/):** Core homework exercises on variables, averages, loops, and variable scoping rules.
  - **[Daily Questions](other-platforms/daily-questions/):** Daily problem sets testing conditionals, switches, and loops.
  - **[Practice Basics](other-platforms/practice-basics/):** Matrix operations, number palindromes, bit swaps, and array searches.
  - **[Recursion Practice](other-platforms/recursion-practice/):** Recursive index searches and number formatting.

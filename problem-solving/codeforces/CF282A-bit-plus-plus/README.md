## 📖 Problem Summary
The programming language Bit++ has one variable `x` initialized to 0 and two operations: `++` (increments x by 1) and `--` (decrements x by 1).

---

## 💡 Intuition & Approach
Read `n` statements. If string contains '++', increment `x`. Otherwise decrement `x`.
